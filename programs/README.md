# Blockchain and Machine Learning practical programs

This repository directory contains source code, tests, and run instructions for Practical Work 1 and Practical Work 2. It intentionally excludes reports, screenshots, generated test output, deployment artifacts, `.env` files, and `node_modules`.

- `practice_01_blockchain/`: educational Python blockchain, peer-node demo, attacks, experiment, and automated tests.
- `practice_02_smart_contracts/`: Solidity crowdfunding dApp, Hardhat tests, deployment/indexing scripts, and frontend.

Each project has its own README with commands and requirements.
