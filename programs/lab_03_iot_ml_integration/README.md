# Лабораторна робота № 3: машинне навчання та інтеграція IoT IDS

Проєкт поєднує модель Random Forest для виявлення атак у трафіку ToN_IoT, API FastAPI, локальні смартконтракти Hardhat та браузерний інтерфейс. Oracle записує клас рішення, версію моделі та SHA-256 канонічного потоку в `DeviceQuarantine`; інтерфейс показує стан пристроїв, пояснення SHAP та журнал подій.

## Передумови

- Python 3.14, Node.js 22 та npm.
- MetaMask або сумісний EIP-1193 гаманець для браузерної роботи з локальною мережею.
- Навчений Random Forest та приклади потоків включено в `models/`. Початковий набір ToN_IoT не включено до репозиторію.

## Запуск локальної демонстрації

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
npm ci
python scripts/run_demo.py
```

Скрипт компілює контракти, запускає локальну Hardhat EVM з chain ID 31337, розгортає систему, запускає API й вебінтерфейс. Відкрийте <http://127.0.0.1:8080> та під'єднайте гаманець до локальної мережі. Документація API доступна за адресою <http://127.0.0.1:8080/docs>.

У вебінтерфейсі власник реєструє віртуальні пристрої та надає оператору тимчасовий дозвіл. Після надсилання прикладу мережевого потоку відображаються прогноз, SHAP-фактори та хеш транзакції. Для атакувального потоку контракт переводить пристрій у карантин, а gateway відхиляє його команду. Екрани аудиту й цілісності показують події контракту та результат повторного обчислення SHA-256.

## Перевірки

```bash
python -m pytest -q
npm run compile
python scripts/e2e_smoke.py
```

E2E сценарій піднімає ізольовану локальну EVM і перевіряє реєстрацію, дозволи доступу, нормальне та атакувальне рішення, карантин, правила gateway, аудит, цілісність даних і негативні випадки.

## Повторне навчання

Щоб повторити експеримент, помістіть наданий для курсу CSV-файл ToN_IoT за шляхом `data/raw/ton_iot_network.csv`, після чого виконайте:

```bash
python -m app.train --data data/raw/ton_iot_network.csv
```

Моделі, їх картка та приклади потоків містяться у `models/`; числові зведення експерименту - у `artifacts/`. Команда `python scripts/render_diagrams.py` повторно генерує схеми з вихідних DOT-файлів.

## Налаштування та безпека

Скопіюйте `.env.example` до `.env`, якщо потрібно змінити адресу RPC або oracle signer. Для локальної демонстрації приватний ключ необов'язковий: Hardhat надає локальний тестовий oracle-акаунт. Не використовуйте тестові ключі для реальних коштів і не комітьте `.env`. У блокчейн записуються тільки клас рішення, confidence, версія моделі та SHA-256; сирі IP-адреси, мітки й ознаки залишаються поза мережею.
