# ADR-0002: Потоки й модель зберігаються поза блокчейном

- **Статус:** прийнято.
- **Контекст:** мережеві потоки та модель значно більші за стан контракту; IP-адреси й деталі інциденту не повинні бути публічними on-chain.
- **Варіанти:** повне зберігання в EVM, IPFS, локальна SQLite/файли.
- **Рішення:** локальні SQLite/файли для даних та моделі; контракт зберігає тільки мінімальні decision fields і SHA-256 digest.
- **Наслідки:** низька on-chain вартість і простий локальний запуск; доступність офлайн-даних залежить від локального сховища й резервного копіювання.
