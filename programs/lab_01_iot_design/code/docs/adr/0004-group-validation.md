# ADR-0004: Групування розбиття за source IP

- **Статус:** прийнято для первинної оцінки.
- **Контекст:** у записах повторюються source IP; випадкове розбиття потоків може дати моделі змогу використати специфіку відомого джерела.
- **Варіанти:** випадковий stratified split, часовий split, group split за source IP.
- **Рішення:** використовувати StratifiedGroupKFold із `src_ip` як групою; сам IP не подавати як ознаку.
- **Наслідки:** перевіряється перенесення на невідомі джерела; частки класів між групами можуть відрізнятися, що звітується явно.
