# ADR-0005: Карантин з ручним зняттям

- **Статус:** прийнято.
- **Контекст:** false positive може перервати роботу нормального пристрою, а автоматичне відновлення може знову відкрити доступ скомпрометованому вузлу.
- **Варіанти:** автоматичний quarantine/release, лише повідомлення, карантин з ручним release.
- **Рішення:** порогове рішення моделі фіксує карантин, шлюз відхиляє команди, owner знімає обмеження окремою транзакцією після перегляду інциденту.
- **Наслідки:** залишається human review, зате кожна зміна має власника та подію аудиту.
